# 打印前准备动作

基准 BK：384a9bb（用户确认尺寸合适的上一版），尺寸映射、985us列周期、
120us匀速步周期及原进纸比例均保留；按用户后续要求，总行程增加2mm。HC32继续使用eb46357。
新启动标记 APP_SERVICE_CMY_BOOT_PREP_V13。

## 视频中可观察的事实及边界

参考视频 15df6d450b11f877ccc29a05cdddfe79.mp4，约68.37秒、30fps。
0秒字车在画面右端；约1.6秒开始向画面左侧移动，之后连续往返；
纸张及已打印内容随后从下方逐步露出；约61–63秒结束时字车在画面右端。
摄像机在移动，纸张开始时被机构遮挡，不能准确换算首次上纸毫米数。
不能从外观分辨每次早期往返是刮擦、空白图像条带还是已经喷墨；
也不能据此断言吸墨、预热、回零、封帽已经发生。画面左右不等同于GPIO命名。

启动进纸的作用是将纸从插入/夹持位置送到首行打印位置，独立于后续逐条带进纸；
字车准备动作可用于离开停放位和经过维护机构，但实际刮擦或机构联动必须实测。
没有传感器反馈的往返不能称为回零，也不能保证解决隔夜空白。

## 本分支实际动作

APP数据完整通过并成功分配/准备图像后，第一条图像条带之前执行一次：

1. 从已知的计数LEFT原点向RIGHT执行原有定时器空行程，喷头关闭。
2. RIGHT端关闭喷头；根据独立的 PRINTER_STARTUP_LOAD_STEPS 执行初始上纸。
3. 原有定时器空行程返回LEFT，喷头关闭；随后开始图像第0行。

这是显式的实验准备序列，不声称复制了样机隐藏固件的准确次数或先后关系。
图像尺寸和条带保持原值；两次准备行程不消耗图像像素、不改变条带方向。
初始上纸调用独立的motor_page_load_keep_power，最多5000脉冲，采用较缓的
3000→1000us低电平梯形参数，保持U4端点微步相位及升压电源；常规条带进纸仍
保持原396/397脉冲快速参数。任一阶段失败即停，不继续返程或打印，外层锁定任务。

目前初始上纸距离尚未实测，因此 PRINTER_STARTUP_LOAD_STEPS 默认0，明确打印
[PAGE_PREP_LOAD] disabled reason=OFFSET_UNCALIBRATED；当前只启用无喷墨准备往返。
不要把这一日志解释为已经完成上纸。待用户确认首次上纸距离后设置固定偏移。
已有进纸粗测11700脉冲/30mm，约390脉冲/mm；它只适合初次估算，仍需实测。

## 验证

实际缓存定时器测试检查准备往返均无点火、端点与原版一致、在RIGHT端上纸，
并覆盖默认0偏移和780脉冲示例。780只是主机测试值，不是发布固件的默认值。
独立失败测试覆盖去程/喷头关闭/上纸错误及短发/返程错误、未知原点及错误起点；
进纸脉冲测试验证新加载函数的有效范围和U4不复位、常规快速进纸保持原行为。
相关SDK对象编译通过；这些检查不能证明纸移动或喷头被有效擦拭。

用户下一步只需量样机首次上纸的大约毫米数，或者提供纸边可见的参照位置。
在该数值确认前，不要求用未标定上纸偏移反复试打。

## 开机往返与行程更新

用户要求“整个字车行程增加2mm”：两端各加187步（按7480步约40mm），
margin由1590变为1777，单程由10660变为11034步。图像尺度、列周期985us、
匀速120us/步和两端400步缓变不变；喷墨窗口仍居中，新增区间不增加图像数据。
几何LEFT原点相应向原来的LEFT外侧移动约1mm；首次使用须对齐这个新原点。
无霍尔反馈，不能靠启动代码判断字车实际在何处，不能宣称自动回零。

新增printer_run_boot_carriage_prepare：通信自检成功后，BLE与打印任务启动前，
只执行一次head-OFF LEFT→RIGHT→LEFT往返，然后关闭驱动。开机调用明确禁止
初始上纸，即使未来启用每页上纸偏移，开机仍不进纸。失败则停止，禁止APP打印，
不尝试盲目回程。每页准备动作仍保留，作用与开机准备分开记录。

这种往返可以经过现有刮片/维护区域或释放停放机构；是否清洁、是否与机构有效
接触须实测。样机可能还通过传感器定位，仅凭视频不能断言同样的软件实现。
上纸距离暂时保持0，后续按用户要求结合霍尔检测确定，而不猜固定毫米数。

## A/B与喷嘴端部

用户A/B指同一喷嘴长条远离/靠近触点的两端。当前每条带固定使用喷嘴表第0–23排，
是按物理Y降序的大Y端约1mm范围；首排Y约9482.35um。并不是从这一端一路
切换到另一端，后续条带也使用相同24排。实际芯片地址扫描仍按现有A/S顺序。
裸芯片规格书没有给出该墨盒封装A/B与坐标原点的对应图，因此不能据此确认A或B，
也不能证明与样机使用的端部相同；本次没有翻转喷嘴映射或进纸方向。

## 当前密封侧、海绵侧和进纸时序

密封侧和海绵侧各外移 187 步。以旧版实机日志最后一次全程 11067 步作为
标定，密封侧至 GPIO24 固定为 11254 步。开机及打印准备的自动闪喷寻到 GPIO24
后，喷头关闭，按计步继续朝海绵走 187 步，停稳后才闪喷。
GPIO24 必须在扩展动作及闪喷时保持低电平。全行程标定为 11441 步，
每次回同一密封停靠点，避免反复开机累积偏移。

打印准备先在喷头关闭时做两次 3740 步小往返，再做三次闪喷往返。前两次返回密封侧，第三次从打印起点去海绵，
第三次 GPIO24 到位窗口以上一次全程实测去程减 935 步为中心，允许偏差 64 步。
第三次闪喷后断墨，U4 朝海绵再推 187 步，累计越过 GPIO24 374 步。
随后补偿这段偏移，回到原打印起点，再一次进纸 3900 步，约 10 mm。正式扫描
保留距 GPIO24 的 187 步空间和密封侧 935 步的内缩。
检查 `WASTE_POSITION endpoint=PAD_EXTENDED advance_steps=187`、
`CARRIAGE_STROKE full_steps=11441` 和 `PRESPRAY_VISIT_DONE`。
密封接触和新海绵位置的接墨情况需要实机确认。

全行程、闪喷和正式打印在端点至少停留 1 秒才反向。闪喷、进纸和其它
停车等待计入这 1 秒。两次小范围往返沿用原折返时序。实机观察确认
这段行程位于密封侧，远离海绵侧刮刀。它按计步折返，完成后回到原计步
位置，机械用途待确认。海绵侧寻位的保护由 GPIO24 和计步上限执行。
保持同一方向的
GPIO24 后 187 步定位段沿用原停稳时序。
