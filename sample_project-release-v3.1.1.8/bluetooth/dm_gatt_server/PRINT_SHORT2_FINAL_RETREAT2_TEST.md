# V23：喷墨扫描缩短2mm，最后无喷墨退刀追加2mm

启动标记APP_SERVICE_CMY_PRINT10660_PARK2MM_V23。BK分支codex/printer-startup-load-prep，
HC32仍eb46357，不需修改。

按用户“喷墨阶段行程缩短2mm，最终退刀增加2mm”分配两个阶段：

- 喷墨扫描11034→10660步，减少374步约2mm。
- 喷墨LEFT结束后再无喷墨退374步约2mm到刮刀；这个尾段单独执行。
- 从海绵光耦参考点到刮刀总距离仍11034步，未恢复会碰边的11408步回程。
  若末行停海绵侧，最终回程是完整11034步；若末行停喷墨LEFT，只补374步。
- 开机仍搜索上限11408、触发后回11034；第二阶段仍单独配置，同样上限11408/
  回11034、六次并行进纸702脉冲共10.8mm；第一阶段20mm两轮保持原值。

维护左端坐标相对喷墨LEFT为-374步；开始图像前空走到喷墨LEFT，扫描期间不越入
这段退刀尾区。图像列距4389、985us列周期、120us匀速步周期、400步缓变保持。
1180列及原图像宽高比例保持；有效图像按缩短后的扫描段重新居中。
第一列同步点为491步，晚于400步缓变；最后有效列也在末端缓变之前。
不能把“追加374步退刀”再次叠加到“从光耦回11034步”上，否则会重现碰边。

TRAVEL_PLAN同时打印print=10660、final_return=11034、final_extra_retreat=374，
用于区分扫描、全回程与尾段追加，避免再把三个含义混为一个行程。

实际缓存/定时器测试通过双向10660步/1180列、六次进纸、光耦正常续打，
以及结束在喷墨LEFT时只退374、结束在RIGHT时回11034；首末列都在匀速区。
复现11057步到光耦后回11034的防过退测试和分阶段不同参数测试继续通过。
相关SDK对象编译、准备顺序与图像控制器回归检查通过；实际停车仍需验证。
