# V19：维护行程加2mm，喷墨行程不变

BK分支codex/printer-startup-load-prep；启动标记APP_SERVICE_CMY_MAINT_PLUS2_V19。
HC32保持eb46357。以V18的喷墨两端作为固定坐标，刮刀维护端点单独向外延伸2mm。

| 位置 | 相对原喷墨LEFT的计数坐标 |
| --- | ---: |
| 加长后的刮刀维护端 | -374步 |
| 喷墨LEFT | 0步，保持原位置 |
| 喷墨RIGHT/另一侧维护端 | 11034步，保持原位置 |

- 第一阶段每个单程由3740步约20mm增加为4114步约22mm，仍往返两轮。
  从新刮刀端-374步向内走到3740步；内端位置与V18相同，外端多走约2mm。
- 第二阶段每个单程由11034变成11408步，仍往返三轮。每个单程同时进纸
  702脉冲约1.8mm，六次4212脉冲约10.8mm；全程禁止喷墨。
- 第二阶段结束在刮刀维护端，先无喷墨向内走374步到原喷墨LEFT，再开始图像行。
- 喷墨每程保持11034步，原列距、图像尺寸、1180列、首列位置和方向补偿均不变。
- 打印结束回刮刀：若从喷墨RIGHT返回，行程11408步，比原来多374步约2mm；
  若已经在喷墨LEFT，则再向外退374步约2mm，也能到同一维护端，而不原地结束。
- 开机仍只做一次无喷墨完整往返，采用这两个维护端点11408步，不进纸。

没有把维护延伸加进喷墨行程；维护位置、喷墨LEFT、喷墨RIGHT三个状态单独区分。
中途错误标记位置未知，停止且不盲目返回。没有传感器回零，首用新版本时
须把计数LEFT初始位置对齐新刮刀维护端，相对V18向外约2mm。

## 验证

真实定时器模拟采用固定的旧喷墨坐标：维护范围扩到-374至11034步，
验证22mm刮擦、六程11408步/共4212纸脉冲、回到原喷墨LEFT，随后各方向
首列及全部1180列物理位置与V18完全相同。直接执行实际finish函数，
覆盖最后停喷墨LEFT时再退374步、停喷墨RIGHT时返回11408步，均到-374；
另测返回中IRQ错误则停止。开机往返零进纸、阶段失败停止与图像控制器回归通过。
相关SDK对象编译检查通过。实物接触、毫米数和出墨仍需验证。
