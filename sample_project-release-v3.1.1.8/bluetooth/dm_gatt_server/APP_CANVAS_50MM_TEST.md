# APP 画布约 50mm 宽测试

BK 分支：codex/printer-app-width-50mm。HC32 保持 eb46357（clock_init_v2）。
恢复点：两个仓库共有标签 backup/printer-pair-20261117-1740。

## 行为

APP 虚线框是整张画布，映射到约 50mm 宽；1180×1476 的源画布约对应
50×62.5mm。虚线框内的白边保持原样，不能按图像非白部分填满纸宽。
源图在框内约占 74% 宽时，图像内容应约 37mm 宽。

字车仍从同一 LEFT 原点开始，单程仍为 10660 步，匀速段仍为 120us/步，
两端仍为 400 步缓变，不增加机械外行程。改变的是现有行程内的喷墨区间。
往返第一个列同步点距各自起点均为 491 步，所有有效列处于匀速区。
HC32 每列周期从 720us 改为 985us（现有协议支持），列数仍为 1180；
CMY 水平补偿后画布宽 1139 列，映射列距 4389×0.01um，画布约 49.99mm。
已知 7480 步约 40mm 是粗测值；时间列距约 43.895um，仍需实测标定。

进纸每 24 行仍为 396/397 步，不通过拉大行间进纸来放大；按新物理列距
重新保持整张画布纵横比例，输出为 1139×1477，条带数从 42 增为 62。
往返同步点取整的理论配准误差小于一个电机步（约 5.35um）。
过去名为 margin_each 的 1590 是旧 40mm 内区两端至端点的几何划分，
不能继续把它理解为新 50mm 画布两侧各 8.5mm 的禁喷宽度。
实际纸宽、居中及可喷边界需要首张纸检查；不要移动原点或加大总行程。

## 一次实机检查

更新并烧录 BK，启动标记为 APP_SERVICE_CMY_CANVAS50_V11；HC32 不更新。
打印同一张掌机图片一次，拍整张纸和尺子，并保留 [PAGE_PLAN]、[PAGE_SIZE]、
[LINE_BUFFER_RESULT] 日志。核对图像内容的宽、高及左右边缘是否在纸内。
若不出墨，这张纸不能用于尺寸校准，先保留日志，不连续空打。

## 验证与限制

定时步进/HC 独立列时钟的主机测试覆盖双向 1180 列位置、全列匀速区间、
主任务调度延迟、CRC/忙定时器/中断迟到故障停止；实际渲染器在原列距和
新列距分别核对全部 CMY 数据及纵横比例。SDK 相关对象编译检查通过。
这些检查不能确认实物纸边、实际移动毫米数和出墨。

隔夜空白没有在此修改中解决。当前打印后停 LEFT 并关闭驱动，未新增清洗、
吸墨、喷墨预热或保湿动作；须先确认与样品机停机位置及维护机构的接触。
