# 按图形部件拆分：先只打印外框

沿用BK c60eafc实际APP图片模式、HC32 3e7e161。无需更新/烧录代码，不要求示波器。
图片不是固件替代图，APP实际发送这些PNG。电压、CE、速度、3170进纸与2秒等待均不改。

图片尺寸均1180x1476，外框坐标和12像素线宽与G1一致，不裁掉画布白边、不自动放大局部。

- F1-full-frame.png：原外框，去掉全部文字/数字/内部横线与斜线。先只打印这一张。
- F2-horizontal-edges.png：只留顶部和底部边线，检查少量喷嘴行形成的横线；待F1后再决定。
- F3-vertical-edges.png：只留左右边，检查跨喷嘴行/条带的连续性；待F1后再决定。
- F4-cyan-frame.png：与F1同几何，改为纯青色源图；只有需要分开CMY时再使用。

F2包含角点，F3不重复角点；两者逐像素不重叠、合并正好等于F1，已程序检查。
PNG模式RGB无透明。F4纯青色源图仍由APP色彩转换，不能宣称是原生仅D1/D2的底层命令。
黑色图在本三色喷头上通常由CMY合成，不是独立黑色喷嘴。

各图在不同纸上独立对照。不要连续发送F2/F3企图在同一纸上叠出F1：
当前每个任务会进纸，不自动回退纸张或保存跨任务叠印原点。
原生完整图本来已按192行从上到下分条带，日志条带不是单个S段。
这里是按图形内容隔离，不等于改变喷头内部驱动顺序。

同一喷头、同纸种、同清洁方式及纸张初始位置，记录时间；APP选原图、无滤镜、无镜像/旋转。
先印F1，标纸F1，发整图/近照和两端日志；不先连印四张。
F1若仍缺，再依缺失位置选择F2/F3，不继续添加复杂图形掩盖定位。

解释限度：
- F1比G1完整：去掉内部内容后工作状态变化，支持内容/负载相关因素，不直接证明某个元件故障。
- F2横边完整而F3竖边按高度缺段：支持行/分段/拼接或喷嘴路径问题，需再核对条带位置。
- 左右边不一致：结合已做过的扫描方向结果，不能直接归为某几个堵塞喷嘴。
- F1黑色偏色而F4青框完整：优先比较颜色域及合成，仍不能用单张证明某色域硬件坏。

F1/F3通常5次非空扫描、5次进纸；F2中间空白条带会跳过扫描但照常进纸，
所以时间、电源开关次数、喷墨负载不同，不能把改善唯一归因于点数减少。
图中定位到的缺失是工作条件下未出墨，不以日志fired计数代替真实喷墨。
生成脚本tools/make_frame_images.py可重建。此提交只有资产与说明，未修改固件源文件。
