# task852 首轮停喷A/B记录

用户提供BK完整日志、HC32同步日志及纸面照片。固件模式IDLE_AB_V1，run=1、order=AB、cache=CAPTURED；用户此前报告连续CE版本实测tFire约1.8us。本轮前擦拭情况和实际轨电压未随日志重新确认，不据此假定条件。

## 数据与调度核对

- 12次扫描均1180/1180列，冻结单帧118000字节、CRC=6B3BDF59；所有REF/OBS同CRC。
- A_OBS1 active_gap_ms=60017；B_OBS1 active_gap_ms=60017。均通过60000±100ms条件，等待期间无列SPI。间隔为有效列成功ACK边界，不是墨滴直接测量。
- A参考与观察各3540列、354000字节，CRC均8F628343；B全阶段7080列、708000字节，CRC=BED31FD8。invalid=canceled=0。
- 独立使用zlib crc32_combine，将单帧6B3BDF59按118000字节重复组合：3次得到8F628343；6次得到BED31FD8，均与HC32一致。各D域的B计数也是A单会话的两倍。
- 所有数据均在S2，地址掩码004A2912包含Add2/5/9/12/14/18/20/23；D掩码3F。旧固定ROW_C/M/Y参考喷嘴统计为0不能解释成CMY无数据，RX_AUDIT已确认六个D域都有数据。
- A在参考3条之后OFF、恢复后ON，再打观察3条；B参考与观察之间没有OFF/ON，会话累计6条。A关电日志约13:43:27.848至13:44:19.893；有效列停喷时间仍为60.017s，包含回程、走纸、恢复等阶段。

## 照片观察及边界

按纸面从上到下：1..3 A_REF，4..6 A_OBS；7..9 B_REF，10..12 B_OBS。12条均能辨认，本轮没有出现整条完全空白。

A_REF1与A_OBS1看起来较浅、偏青，可见左端较短；后续线更完整、更深。B_OBS1仍有明显线条，颜色相较B_REF偏品红。照片仅支持定性观察，光照/混色/淡黄色可见度影响判断，不能据此精确量化CMY缺失或断言某域电路故障。可见起点变短不等同于控制器漏发整列。
