# 第二阶段：字车三轮往返，每单程进纸2mm，共12mm

BK分支codex/printer-startup-load-prep，启动标记APP_SERVICE_CMY_WIPE20_PARLOAD12_V17。
HC32保持eb46357，不需更新。

## 本次动作

- 原V16总行程11034步，再加总计2mm：两端各187步，单程11408步。
  LEFT计数原点相对V16再向外移约1mm，打印区仍在总行程内居中。
  图像毫米比例、列周期985us、正常匀速120us/步和两端缓变保持不变。
- 第一阶段保持：刮刀端单程3740步约20mm，往返两轮，共四腿，喷头关闭。
- 第二阶段修改：不是一次性进纸10mm，而是字车完整往返三轮，共六个单程。
  每个单程并行进纸780脉冲约2mm，累计4680脉冲约12mm。
  字车按RIGHT、LEFT、RIGHT、LEFT、RIGHT、LEFT交替，六程后停在LEFT。
- 六程都成功后才开始图像打印；首条图像行从LEFT朝RIGHT，使用原图像映射。
  六程中喷头全程OFF，没有ARM、SYNC或点火；不会多补一次10mm。
- 开机仍只有一次完整无喷墨往返，不进纸。后续逐条带进纸仍为396/397脉冲。

每程都用现有TIMER4驱动字车，进纸由主任务运行。若一台电机先完成，
等待另一台完成再开始下一程；每程结束记录累计进纸步数。中间故障停止，
不自动补足、重复或盲目回程。字车错误通过U5逐步停止回调中止进纸。
图像控制器在整套准备成功前不会进入点火阶段。

## 测试证据与实机限制

真实定时器模拟检查六个单程各11408步、右左交替并最终回LEFT；
进纸在每个单程运动中发生，六次780脉冲合计4680，全程零点火，
随后第一条图像行完整播放1180列。准备顺序测试额外覆盖第3程、第6程失败，
确保不进入下一程或图像行；保持开机零进纸与原双向图像物理位置回归。
相关SDK对象编译与diff检查通过。毫米数仍基于原粗测，计数不能证明纸实际移动。
