## 参数独立

在printer_service_geometry.h中分开定义：

| 用途 | 搜索上限 | 从OC3参考点返回 |
| --- | ---: | ---: |
| 开机 | PRINTER_OC3_BOOT_SEARCH_STEPS=11408 | PRINTER_OC3_BOOT_RETURN_STEPS=11034 |
| 第二阶段 | PRINTER_OC3_PREP_SEARCH_STEPS=11408 | PRINTER_OC3_PREP_RETURN_STEPS=11034 |
| 喷墨扫描 | PRINTER_SERVICE_SPAN_STEPS=11034 | 原有效喷墨坐标、列时序保持 |
| 最终回刮刀 | 不搜索 | PRINTER_OC3_FINAL_RETURN_STEPS=11034 |

虽然当前几项回程初值同为11034，它们是独立参数，不再联动。开机完成后仅关闭
电机，不再调用“最终停放”函数覆盖开机的位置。记录阶段左端相对喷墨LEFT的有符号
偏移，在开始图像前归一到原打印坐标；不同阶段细调不会自动拖动图像起点。

取消额外374步（约2mm）退刀：原打印LEFT即当前初始安全停放点。
这同时取消从过深维护端再向内补走374步，因此以OC3为基准的实际喷墨坐标不变。
第一阶段单程20mm两轮、第二阶段三轮/每单程702纸脉冲，累计4212脉冲约10.8mm保持。

开机和第二阶段的向外搜索上限与返回距离分开，必须真实检测到OC3才建立RIGHT参考。
若到搜索上限仍未检测到，停止并记录OC3_NOT_FOUND；不把搜索最大步数当成已到位点，
再盲目走一个固定回程。正常光耦触发仍会反向并继续流程。
