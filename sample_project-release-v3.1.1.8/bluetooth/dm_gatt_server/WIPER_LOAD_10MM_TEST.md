# 每次打印送纸10mm与刮刀端小范围往返

按用户“每次打印前进10mm”作为准备阶段总量，只有一次10mm。
用户明确10mm属于进纸马达，不是字车额外走10mm。

## 动作

APP数据与图像准备通过后：

1. 在原LEFT刮刀端，确认HC32协议并关闭喷头，开启并保持电机电源。
2. 纸张按原前进方向送3900脉冲，约10mm。使用现有11700脉冲/30mm粗测值；
   不等待光耦/霍尔，不读取纸传感器。此次偏移独立于逐条带396/397脉冲。
3. LEFT端向行程内部走187步、原路返回187步，重复两轮，共四个短单程。
   暂按保守约1mm试验幅度，不声称已经精确复制样机刮擦距离。
4. 回到LEFT后，按原图像条带开始朝另一端打印。没有另加字车10mm，
   没有再加一次纸张10mm，没有修改图像尺度或图像打印窗口。

短行程使用已有TIMER4步进中断，GPIO脉冲不等待HC32；每腿两端采用原缓变曲线，
主任务仅等待完成。没有喷墨同步信号、没有额外点火。中途故障停止，不盲目返回；
纸张部分移动后失败也不自动补足或倒退，任务锁定直到重新建立初始位置。

总字车行程仍11034步（前次增加2mm后的数值）。开机无喷墨完整往返一次保持，
即使每页配置3900步，开机调用仍跳过送纸和短程刮擦。
尺寸保持用户确认的384a9bb基准，列周期985us、120us匀速步距均保持。
启动标记 APP_SERVICE_CMY_WIPE_LOAD_V14，HC32仍为eb46357，不需重烧HC32。

## 验证

主机测试通过：正常双向打印1180列；短程两轮精确返回LEFT；整个短程零点火；
中断迟到时原地停止且不返回；初始送纸在刮擦之前；3900脉冲真实进纸函数的
范围/供电/相位保持；短发或错误则不继续运动；开机一次性调用不送纸；
原图像控制器回归与相关SDK对象编译检查。

尚待实机：实际送纸毫米数、LEFT是否确为刮刀侧、1mm往返是否跨过有效刮擦面、
准备动作是否有助于恢复出墨。计数与日志不能证明喷头已被清洁或纸实际移动。

## 一次实机检查

只烧录BK。按先前要求对齐增加行程后的LEFT起点，开机应空往返一次且不送纸。
随后发一份任务，观察纸只先送一次约10mm，LEFT端短程往返两轮，再正常打印。
拍到纸边及字车的短视频，并保存[PAGE_PREP_LOAD]、[WIPER_LEG]日志。
先检查动作顺序与实际刮擦接触，避免把未出墨继续归因于图像数据。
