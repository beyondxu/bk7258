# 模式3空白后的下一步：先测供电，再测波形

当前证据：BK模式3完成扫掠/回程，HC收到slot40、data01、active_bits1且喷射函数返回；纸上无可见墨迹。
这不足以证明喷头供电、加热时序或实际出墨正常。

## 本轮只测供电（模式4）

BK同一分支更新后，将printer_diagnostics.h的PRINTER_STARTUP_DIAGNOSTIC改为4，重新编译烧录BK。
HC原握手版本可继续配合；HC最新提交只修正供电日志中的引脚名称，不改变波形。
两端一起断电重启，不连接APK发送任务。

BK输出 `[DIAG POWER] 30-second measurement window` 后，30秒内不下发任何喷射列，也不移动电机。
结束输出 `window closed; boost disabled`。应在该窗口内测量，不要用窗口结束后的电压判断上电是否成功。

万用表黑表笔接板GND，记录：

| 原理图网名 | 便于定位的元件/节点 | 规格书参考 |
|---|---|---|
| VDD_15V | Q4/Q5电源输入侧 | 升压设计约15V |
| VDD_VL | C47非GND端 | 喷头VL，12～15V，典型15V |
| VDD_TPH | C45正端或C46非GND端 | 喷头VP，12～16V，典型15V |

以实际板上网名、走线和测点为准，不按照片猜焊点。日志只证明使能指令已执行，不是电压反馈。
原理图第2页：VL_ENABLE接HC PB6；TPH_ENABLE接HC PB5。
原日志PB7/PB6是文字错误；驱动宏使用PB6/PB5，与原理图一致。

请先返回三项电压及模式4日志；本轮无需喷墨照片，不再执行模式3。

## 供电确认后的示波器准备（尚不要求再次喷射）

- CE：HC PB15，对应喷头连接器X2的CE网络。
- S1：HC PC15，对应X2的S1网络。
- D1：HC PA0，对应X2的D1网络。
- 示波器探头地接板GND，逻辑信号约3.3V，使用10倍探头。
- 后续捕获应同时观察CE、S1；有额外通道时加D1和S4。采样率至少100MS/s，优先更高，时间轴先1us/div。

M0333N V1.2印刷第11页（PDF第14页）：CE在连续地址序列期间保持有效；S低采样至少0.38us。
tFire图示跨同一S在相邻地址的更新间隔，典型2us、最大2.2us；不能把它直接等同于任意CE高脉宽。
现有TPH_FireOneColumn每地址拉低CE，与该图存在明显差异，可能提前截断锁存数据的加热时间。
下一步将用实际波形核对后修改，而不是增大NOP或持续试喷。
