# 短打印：区分重新启动、重装触点与擦拭

当前默认 `APP_CMY_SHORT_V1`，一次只打印原始CMY长线3次，约30秒正常结束，无5分钟等待、预喷或启动自动运动。HC32保留当前连续CE及实测tFire约1.8us版本。

用户补充：擦拭必须取下并装回喷头；修改时序后多数时候没有擦拭。因此过去“擦拭后恢复”同时包含重装接触变化，不能直接当作喷嘴堵塞或喷嘴面清洁的证据。按用户判断，机械扰动暂不作为优先排查方向。

## 按顺序做，恢复则先停下记录

1. **基线**：刷机后先不擦拭、不拆装，原图触发一次，正常打印3条后结束。若已正常，先回传，不再立刻拆装；刷机/重新启动及等待也可能改变状态，不能认定此前触点坏。
2. **只重新启动**：若基线仍偏红/无墨，完整结束并确认 `IDLE_AB_END code=0`、喷头OFF，再整机断电约1分钟，期间不碰喷头、排线或触点；重新启动，发送原图一次，打印3条。
3. **只重装、不擦拭**：若只重启后仍异常，完整结束后整机断电，取下再按原方式安装喷头，不擦喷嘴面、不清洁触点、不额外换排线。断电时长尽量同上约1分钟，若实际更久请记录。重新启动后再发送原图一次，打印3条。

每一步是一次APP触发，各3条；不用一口气做完全部。所有取装必须在整机断电后进行；不要为了保留缓存而带电拔插。每组三条之间不擦拭、不复位、不中断。打印序号和位置、所有空白均保留。

暂时不做“擦拭+重装”的第四步，先看前面结果，避免再次把因素合在一起。

## 如何解释

- 不动喷头、只重启就恢复：优先查重新启动/等待相关状态，不能将恢复归于触点重装；恢复是否稳定仍需复核。
- 只重启不恢复，重装不擦后恢复：说明擦喷嘴面不是该次恢复的必要动作，触点接触更值得检查；不能仅凭一次结果就判定触点故障，不能彻底排除供墨或其他状态因素。
- 重装也无变化：触点重装未恢复本轮现象，不等于全部接触问题已排除；下一步再决定擦拭恢复对照或单色/电气路径测试。

## 数据及日志边界

本次改动只缩短参考组，不改变数据渲染/映射。`IDLE_AB_BEGIN order=REFERENCE_ONLY scans=3 target_gap_ms=0`，`IDLE_AB_PHASE phase=CMY_SHORT reference=3 observe=0`；不会出现等待或OBS。结束有PHASE_DONE scans=3/3及IDLE_AB_END code=0。整个任务一次ON会话，HC32应3540列、354000字节，invalid=canceled=0。

同一上电周期重复APP触发会复用同一118000字节缓存。但整机断电会清缓存、APP转换也可能有少量变化，跨断电的CRC可能不同，不能声称三组必然逐点完全相同。回传完整日志以核对各组C/M/Y是否均有数据、域/地址/S掩码及数量，跨组数据变化不能凭照片排除。只把大范围恢复看作线索，不据此宣布单一硬件原因已确定。

780脉冲两段线间距，第三条后1560脉冲分组间距，按此前标定总指令约8mm；不扩大横向行程或调整尺寸。未改变BK/HC32通信协议。
