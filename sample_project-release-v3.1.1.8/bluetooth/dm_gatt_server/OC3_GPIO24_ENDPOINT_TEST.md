# ADC_OC3 / GPIO24：海绵侧正常行程终点

BK分支codex/printer-startup-load-prep，启动标记APP_SERVICE_CMY_OC3_GPIO24_V21。
HC32继续eb46357，无需重烧。光耦拉低表示正常到位，不是故障报警。

## 引脚与配置

用户规格书533_oc.pdf为TJ-IEL533系列红外光遮断器，输出是光电三极管，
3脚Collector、4脚Emitter。按用户板路定义，ADC_OC3网络在字车靠近海绵侧时
将GPIO24拉低。本实现读数字电平，不启用ADC。

实际板级文件是ap/config/bk7258_ap/usr_gpio_cfg.h（用户给出的路径省略了目录分隔）：
GPIO24由输出改为输入、内部上拉、关闭第二功能、GPIO_DEV_INVALID、
保留初始化使能和禁止分时复用；静态中断先关闭，类型指定下降沿。

bk_motor_gpio_config_init设置电机初始休眠后调用motor_oc3_init：
解除GPIO复用、设置输入上拉、注册下降沿ISR、清状态、再开启中断。
配置失败则不允许TIMER4运动。开机打印OC3_INIT，包含初始电平。

## 到位动作与正常续打

所有当前TIMER4路径朝海绵方向运动时检测GPIO24。下降沿ISR立即停TIMER4，
停止后续STEP并释放SYNC；每个步进周期也读电平，覆盖起动前已经LOW或未收到IRQ的情况。
正在进行的4us STEP高脉冲可能完成；不宣称光电器件/IRQ延迟为零。
反转、SPI和日志均在任务上下文完成，不在GPIO ISR里阻塞。

- 开机：正常到位后先确认喷头OFF，再反向11408步到刮刀侧，继续启动，无进纸。
- 第一阶段20mm两轮保持。若起点不正确而先碰到海绵光耦，则先按固定11408步
  返回建立刮刀端参考，再重新完成一次第一阶段，不把正常光耦到位当成页面失败。
- 第二阶段：朝海绵单程GPIO24到位后停字车，完成该单程的702纸脉冲，
  再正常反向11408步。三轮、六个单程合计4212纸脉冲约10.8mm。
  如果1.8mm纸步比字车晚完成，端点会等待剩余纸步；不会因此取消任务。
- 喷墨：正常RIGHT到位后校验本行1180列完成，继续下一条带LEFT反向喷墨。
  LEFT返回的有效喷墨坐标与旧版完全相同；行末多出的374步是无喷墨回刮刀尾段，
  合计11408步，连续运行，不在原喷墨LEFT处停一下再补走。下一RIGHT行无喷墨
  移动374步回原喷墨LEFT后再开始原数据窗口，图片尺寸及喷墨位置不变。

因此正常LOW不会产生PAGE_FAULT，也不是中止整页后重新打印。
物理光耦到位优先于计数；若在现有步数上限内未触发，则仍按原步数边界停止/返回，
不会无限寻找。OC3_SEEK_END的optical_hit=0表示本次使用了计数后备。
返回方向不响应该低电平，避免重复反转；到刮刀后仍不释放的持续LOW才会停止。

若实际物理端点出现在图像行数据尚未发送完整的位置，无法继续向外喷出剩余图像；
此时记录OC3_PRINT_WINDOW校准信息并关闭喷头返回。这是喷墨窗口/安装位置需标定，
不是把正常到位电平当成电气故障。半行不会被盲目重打。

## 验证

实际GPIO初始化与板级行测试：输入/上拉/关闭复用、IRQ注册顺序、LOW极性、
各初始化失败分支。定时器/缓存实际逻辑模拟覆盖：下降沿打断正在进行的STEP、
无IRQ时电平兜底、起动已LOW零向右脉冲、固定11408步反向、LOW期间能离开、
持续LOW停止、正常维护早/晚到位仍完成各次纸步、正常打印到位后反向续打。
一次完整准备加连续两轮喷墨往返共5次正常光耦到位，所有行1180列完整结束，
无页面失败；额外覆盖过早物理边界的数据未完成保护。原阶段顺序/图像控制器/
U5停止回调回归及相关SDK对象编译检查通过。实机电平和定位仍待验证。

## 一次实机检查

只更新BK。先看开机朝海绵运行：GPIO24变LOW后应停止向前并返回刮刀。
保留OC3_INIT、OC3_ENDPOINT或OC3_RETURN_BEGIN/DONE、OC3_SEEK_END日志。
随后打印原图一次，正常到位应继续反向打印；保留LINE_BUFFER_RESULT和PAGE_RESULT。
