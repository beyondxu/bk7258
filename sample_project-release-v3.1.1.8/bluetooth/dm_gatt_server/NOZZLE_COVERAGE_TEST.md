## 图案

纸上应出现青、品红、黄三组细小阶梯/梳状短线，横向分开放置。
每一物理喷嘴只发12个连续点，逻辑行0..191依次错开横向起点：

- 基础列：C=200、M=450、Y=700；每8行重复一次横向阶梯。
- 每行起点为基础列+(row%8)*14，再应用该物理域的列补偿。
- 每色192条短笔，每笔12点，每色2304点，总6912点；有效列不超过中央200..999范围。
- 同一横向位置每8行出现一笔，便于近照检查缺行，而不是把192行涂成难辨识的实心色块。
- 涵盖S1/S2/S3各50行、S4的42行，即每色各分区600/600/600/504点。
- 图案按颜色分开放置，降低多色同列负载干扰；未增加电压、脉宽或预喷次数。

按规格书名义行距42.33um，每组第一行到最后一行的中心距离应约8.085mm。
注意量的是喷嘴排列方向上整组的覆盖高度，不是短笔本身的横向长度。
纸张/照片可能旋转，以各颜色梳状图的长轴识别喷嘴排列方向。
实测若明显不同，也要记录，不能只把走纸40.64mm视为条带高度已匹配。

## 日志和反馈

BK应有：

```text
[NOZZLE_CHART] rows_each=192 strokes_each=192 dots_per_stroke=12 expected_dots_each=2304 ... feed=0
[LINE_PLAN] result=0 mask=7 dots_CMY=2304,2304,2304 ...
[CYAN_LINE_END] result=0 columns=1180/1180 forward=7480 reverse=7480 ...
```

CYAN_LINE是共用执行器历史名称，三色均输出。
HC32旧ROW_AUDIT只统计固定三个槽位，bars/outside/other_bits不按三段线标准解释。
其中columns/fired应为1180，invalid/canceled应为0；默认三色下，固定槽的C/M/Y dots各为12，
other_bits=6876，总有效点为6876+12+12+12=6912。bars/outside不按旧三段图判断。
本次会使用奇偶两列域，首次非零不再要求是旧的slot73/data0x02。

请提供：同一画面拍三组图的清晰近照并放毫米尺、整组覆盖高度、两个MCU完整日志。
重点看是否有整条空白带或某些阶梯反复缺笔，并记录是哪一种颜色、哪一段高度。
缺笔表示本次工况未观察到该行出墨，不能直接判定喷嘴损坏；可能仍有驱动时序或出墨因素。
若覆盖高度正确且所有行连续，再回到完整图检查进纸的条带拼接；
若有固定分区缺行，应先定位对应分区，继续改进纸步数不能补出缺失喷嘴行。
不要为此反复干打，完成一次取样即可；遇卡顿/撞边立即断电。
