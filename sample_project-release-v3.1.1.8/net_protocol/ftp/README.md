# FTP 服务器示例


## 概述

本示例演示了如何在嵌入式设备上实现一个轻量级、高性能的FTP服务器。它具体展示了如何：

1. 配置 WIFI 信息并连接到指定AP
2. 如何实现多并发FTP连接处理
3. 如何支持各种FTP命令（如USER/PASS、PORT/PASV、LIST、RETR、STOR等）
4. 如何与VFS文件系统集成，提供文件操作功能


## 项目配置、编译、烧录

### 项目配置

项目必要配置，以BK7258为例，查看项目目录下的配置文件（net_protocol/ftp/ap/config/bk7258_ap/config）

```
# 使能VFS、LITTLEFS组件
CONFIG_VFS=y
CONFIG_LITTLEFS=y

# 使能FTP服务器组件
CONFIG_FTP_SERVER=y
```

### 项目编译

运行以下命令进行编译构建：

```bash
# 进入示例项目目录
cd sample_project/net_protocol/ftp

# 编译BK7258固件
make bk7258
```

### 项目烧录

使用烧录工具（BKFIL）进行烧录，以BK7258为例，烧录目标固件（build/bk7258/ftp/package/all-app.bin）

注意：
1. 请确保烧录工具版本与芯片版本匹配，如不确定，请升级最新版本。
2. 请确保烧录工具已连接到开发板。


## 代码解释

### 概述

1. 初始化芯片系统、外设，wifi协议栈等
2. 挂载LittleFS文件系统
3. 连接到指定wifi AP（默认SSID: "sample_project_wifi", 密码: "12345678"）
4. 初始化并启动FTP服务器
5. 处理客户端FTP连接和命令


## 测试步骤

前提条件：需要一个FTP客户端软件（如FileZilla等）

1. 烧录固件：
   - 若使用SD卡文件系统（默认）：仅需烧录固件，无需额外烧录资源文件
   - 若使用LittleFS文件系统：需烧录固件和资源文件（sample_project/net_protocol/ftp/littlefs.bin，默认烧录地址：根据分区配置确定）
2. 设备会自动连接指定AP(默认AP SSID: "sample_project_wifi", 密码: "12345678"),连接成功后，FTP服务器会自动启动，监听21端口
3. 测试电脑连接同一WiFi网络，处于同一局域网内，使用FTP客户端连接到设备的IP地址：
   - 主机：设备获取到的IP地址
   - 端口：21
   - 用户名：admin
   - 密码：admin
4. 连接成功后，可以使用FTP客户端进行文件操作：
   - 浏览目录
   - 下载文件
   - 上传文件
   - 创建目录
   - 删除文件/目录
5. 文件系统挂载路径：
   - SD卡（默认）：挂载路径为"/"
   - LittleFS：挂载路径为"/"，默认包含一个test.txt文件。


注意：
1. 测试电脑需要与设备在同一局域网内，才能连接到设备的IP地址。
2. 测试电脑需要安装FTP客户端软件，如FileZilla等。
3. 如果挂载的是LittleFS文件系统，由于它是只读的，所以ftp无法进行上传等命令。


## 功能特点

1. **轻量级实现**：适合资源受限的嵌入式设备
2. **高并发支持**：可同时处理多个客户端连接
3. **双模式支持**：同时支持主动模式和被动模式数据传输
4. **丰富的FTP命令支持**：
   - USER/PASS：用户认证
   - PORT/PASV：数据连接设置
   - CWD/CDUP：目录导航
   - PWD：打印当前目录
   - NLST/LIST：目录列表
   - RETR：下载文件
   - STOR：上传文件
   - MKD/RMD：创建/删除目录
   - DELE：删除文件
   - SYST/NOOP：系统信息和保活
5. **VFS集成**：与VFS文件系统无缝集成，支持各种文件系统
6. **事件驱动架构**：基于lwIP的事件驱动TCP/IP栈，高效处理多个连接

## 故障排除

1. **连接被拒绝**：确保设备已连接到WiFi网络并获取到IP地址，检查防火墙是否允许FTP连接
2. **数据传输失败**：检查是否支持被动模式，确保客户端能连接到服务器的数据端口
3. **认证失败**：当前版本允许任意用户名和密码，如遇到认证问题，请检查FTP服务器配置
4. **文件操作失败**：确保文件系统已正确挂载，检查文件权限设置
